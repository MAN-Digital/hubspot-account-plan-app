## Data posture

- HubSpot remains the CRM source of truth.
- Provider keys are tenant-scoped and must not be returned to the UI.
- Provider calls send the minimum required fields for the selected action.
- Preview actions do not debit app credits.
- Accepted/generated outputs debit credits according to the configured credit policy.
- CRM writes are explicit user actions only.
