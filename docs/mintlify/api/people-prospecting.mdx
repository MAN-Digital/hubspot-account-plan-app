title: People prospecting API

---

People prospecting lives in the People tab. Buying Group maps real HubSpot/People records after they exist.

## Preview

`POST /api/people/{companyId}/prospect/preview`

Preview normalizes the People modal payload into provider requests:

- Apollo People API Search for structured people search.
- HarvestAPI LinkedIn profile search for LinkedIn candidate and evidence context.
- HubSpot-first dedupe and existing contact context.

Preview creates a prospecting run and candidate drafts, but debits 0 app credits.

If Apollo or HarvestAPI keys are not configured for the tenant, preview returns provider blockers instead of consuming credits.

## Accept

`POST /api/people/{companyId}/prospect/accept`

Accept persists the selected candidate rows as accepted and debits only accepted usable contacts.

Current credit policy: `accepted usable contacts * 4 credits`.

Accept is blocked by tenant balance and the requesting rep's daily, weekly, and monthly caps.
